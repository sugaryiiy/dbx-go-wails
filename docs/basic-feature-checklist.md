# DBX 基础工作台功能清单

更新日期：2026-10-04。对象：公司内部开发、测试及数据人员。当前版本基于 DBX v0.6.33，交付形态包含本地 Web 开发版及 macOS MCP 桌面测试包。

本清单围绕连接数据库、查看结构、执行 SQL、编辑数据、导入导出和复用查询展开。核心能力沿用 DBX；启动脚本、操作引导和示例工作区已完成基础验收。后续已增加 SQL 收藏/历史 MCP 工具，本轮重新组织主工作台与启动页的布局和入口；专业模块内部页面未逐屏重做。新版界面的验收状态在第 10 节单独列出。团队权限、审计、审批和统一登录按当前约定暂缓。

状态说明：第 1–9 节保留此前构建的功能与验收记录，不表示新版界面已逐项复验。**页面通过**表示对应记录中实际操作页面验证；**接口通过**表示真实 HTTP/MCP/数据库验证；**回归通过**表示自动测试覆盖；**已有待验收**表示上游已有实现，但对应记录尚未完成该项使用场景的验收；**部分页面通过**表示已列出的场景通过，剩余场景仍待验证。所有实际数据库验收目前限于 SQLite，不代表其他数据库同步验收通过。

本次主工作台原生复验还包括：数据库树搜索和新建连接入口、结果收起/恢复、历史开关、`⌘⇧A` 搜索历史、`⌘E` 最近页签、AI 隐藏后的 Tools 入口、深浅主题及约 961px 窄窗口执行。详细记录与构建证据见 [macOS 技术说明](macos-mcp.md#工作台布局重构2026-10-04)。

## 9. SQL 收藏与历史 MCP 工具

四个工具复用 GUI 的 SQL 库和历史存储，调用时按允许的连接及数据库作用域处理。GUI 继续使用 HTTP API，外部 MCP 客户端使用 `/mcp`。基础桌面包在 lazy 插件模式下的静态工具数由 24 增至 28；实际列表仍受策略和构建特性影响。

| 编号 | 功能 | 具体操作与边界 | 当前状态 |
| --- | --- | --- | --- |
| M01 | 检索 SQL 收藏 | `dbx_list_saved_sql` 按连接、数据库及可选 Schema 过滤，按名称搜索；默认每页 20 条，最多 100 条，使用 offset 翻页；只返回摘要 | 此前新增；真实包接口通过，名称过滤和分页通过 |
| M02 | 读取 SQL 收藏 | `dbx_get_saved_sql` 按 ID 读取正文；ID 不能跨越所选连接/数据库/Schema 作用域，正文最多 64 KiB | 此前新增；真实包读取、HTTP 正文一致性、跨数据库拒绝及非法 ID 检查通过 |
| M03 | 新建 SQL 收藏 | `dbx_save_sql` 保存名称和 SQL 文本，生成新 ID；同名再次保存仍新建，不覆盖已有收藏，不执行 SQL；只读数据库策略下可保存文本 | 此前新增；真实包接口通过，HTTP SQL 库可见、同名新建及“保存不执行”检查通过 |
| M04 | 搜索 SQL 查询历史 | `dbx_search_history` 按目标连接/数据库、关键词和成功状态检索，仅返回 SQL 查询记录；游标按执行时间和 ID 分页，默认 20 条、最多 100 条 | 此前新增；真实包接口通过，HTTP 互通、相同时间戳分页、内部字段过滤和 UTF-8 截断通过 |

收藏工具当前只支持默认 catalog，名称为 1–255 个字符，保存 SQL 最多 64 KiB。历史结果不返回 MCP 请求/响应、会话标识、details 或 rollback 等内部字段；单条 SQL 返回上限为 16 KiB，错误文本为 2 KiB，明确给出截断标记和 SQL 原始字节数，完整内容仍在 GUI 历史中。历史不记录 Schema 身份，因此不支持限制到具体 Schema 的 MCP 会话。非法 ID、分页大小、游标和超限文本均有错误响应。

这一扩展不包含 MCP 收藏更新/删除、文件导入导出、历史删除或公司级审计。此前的 28 工具桌面包在独立临时后端通过全部 10 组 MCP smoke，示例 JOIN 返回 8 行；结果保存在 `target/macos-mcp/smoke-report.json`，Rust MCP 库的 197 项测试也通过。完整验证范围见 [macOS MCP 文档](macos-mcp.md)。

## 12. 第一版验收口径

基础版完成验收时，使用者应能独立完成：创建真实连接 → 找到表并查看结构 → 编写和执行 SQL → 筛选/分页查看结果 → 修改并预览提交 → 导入 CSV/XLSX → 导出并检查内容 → 保存 SQL 并从历史复用。

此前构建已验证上述流程的 SQLite 核心链路；其他数据库、表格增删、文件向导等未验收项按上表逐项关闭。SQL 库内容保存在 DBX 应用数据中，不是磁盘独立 SQL 文件；查询历史用于本地复用，不作为公司操作审计。

# 数据库工作台 桌面版使用手册

适用于本仓库的 macOS 基础工作台与 MCP 桌面包。界面沿用 DBX 的数据库管理能力，提供本地示例、SQL 工作流、DataGrip macOS 快捷键预设，以及供外部 AI 客户端使用的 MCP 服务。本次重新组织的是主工作台和启动页，专业模块沿用现有界面，未逐屏重做。

## 安装与启动

本机产物位于仓库的 `target/macos-mcp`：

- `Database Workbench.app`：可以直接双击启动，也可以放到“应用程序”目录。
- `Database-Workbench-macos-arm64.zip`：先解压，再打开其中的应用；此包用于 Apple Silicon Mac。

应用包含前端和后端，运行时不需要单独启动 Node.js、Rust 或开发服务器。启动后原生窗口自动登录。默认服务地址为 `http://127.0.0.1:4227`，MCP 地址为 `http://127.0.0.1:4227/mcp`；服务只监听本机。

当前包采用本地 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证。构建声明最低支持 macOS 13，实际验收环境为 macOS 27.0.1 / Apple Silicon；其他系统版本及 Intel 真机仍需验收。

数据默认保存在：

```text
~/Library/Application Support/数据库工作台 Desktop
```

通过原生菜单 **工作台 → 显示数据文件夹** 可以定位该目录。退出请使用 **数据库工作台 → 退出 数据库工作台** 或 `⌘Q`，应用会停止自己的后端。更换 `.app` 不会主动清空此数据目录。

## 认识新版工作台

全局顶栏保留新建连接、新建查询和常驻的 **搜索操作** 入口。DataGrip macOS 预设使用 `⌘⇧A` 打开操作搜索；自定义键位后以界面显示为准。**工具（Tools）** 菜单集中放置数据传输、SQL 文件执行、结构/数据对比、备份、驱动管理、插件中心、字体设置和 MCP 设置。

- **左侧**：40px 导航条提供数据库侧栏开关、对象搜索、新建查询和设置；旁边的数据库栏负责连接搜索及对象树浏览。
- **中间**：页签、查询上下文、SQL 操作栏、编辑器和结果区按层次排列。查询上下文中的连接、catalog、数据库和 schema 随数据库能力显示。
- **右侧**：SQL 库、SQL 文件、历史和 AI 工具入口用于开关对应面板。它们遵循设置中的显示开关；隐藏的入口仍可从 Tools 菜单打开。SQL 文件面板用于浏览文件，与 Tools 中的 SQL 文件执行是两个入口。
- **底部**：状态栏显示实际连接状态、当前连接/数据库、连接数量、运行任务和查询光标行列。没有活动连接时会明确显示未选择连接；MCP 入口打开策略设置，不代表 MCP 服务连接状态。

启动页把打开示例、新建连接、新建查询和导入连接集中在顶部。工作台模式下显示近期连接与已保存查询列表，下面保留操作流程和常用快捷键；介绍模式继续隐藏近期记录。可在设置中选择启动页模式。

## 字体与颜色

界面用字体、字重和文字标签共同区分内容；颜色用于补充状态信息。

| 内容 | 字体层级与颜色 |
| --- | --- |
| 导航与工具栏 | 界面字体；连接和区域标题加粗，常规操作保持普通字重 |
| SQL 正文 | 等宽字体；默认关键字蓝紫、字符串绿、数字橙、字段和表名为主文字色，注释灰色斜体 |
| 数据库与 Schema 上下文 | 名称使用等宽字体，与连接标题区分 |
| 结果表格 | 保留独立表格字体和等宽数字；表头加粗，类型和备注分层显示 |
| 次要信息 | 计数、驱动、光标位置等通常使用 11px 次要文字 |
| 活动项与状态 | 蓝色选中/运行、绿色完成/连接、橙色提示/取消、红色错误或危险操作；保留状态文字和图标 |

数据库树中的连接自定义色显示为名称旁的小色标，选中行统一使用蓝色。默认代码字体优先使用已安装的 Fira Code、JetBrains Mono 等字体；没有这些字体时回退到系统等宽字体，中文保留系统中文字形。旧内置预设会自动修正回退顺序；手写字体列表和显式选择的编辑器主题保留。上表中的 SQL 颜色适用于默认“跟随应用”配色，其他主题采用其自身配色。

打开 **工具 → 字体设置**，或按 `⌘⇧A` 搜索“字体” / `font`，即可定位 **设置 → 外观 → 字体设置**。这里集中提供界面、SQL 编辑器、结果表格三套字体选择，支持搜索本机已安装字体、常用预设和输入自定义字体名称；SQL 字号可调为 10–24px。

选择后查看旁边的中英文、数字预览，点击底部 **应用** 或 **应用并关闭** 保存，重启继续使用。未应用时关闭设置可放弃草稿。**恢复默认字体** 只重置这三套字体和 SQL 字号，不改变主题或其他设置。预设字体如果未安装，会使用回退字体。编辑器主题仍在 **设置 → 编辑器** 中调整。

SQL 关键字和常见内置函数默认以小写补全，例如 `select`、`count()`；已有 SQL、表名、字段名及用户自定义片段保持原样。需要改变时，在 **设置 → 编辑器** 搜索“补全关键字大小写”或“补全函数大小写”，可选小写、大写、保持原样。此设置独立于手动格式化；ClickHouse 等大小写敏感函数保留数据库要求的拼写。

函数着色取决于数据库方言的词表：被识别为关键字或内置名称的函数使用对应颜色，其余函数沿用主文字色。

## 第一次使用：打开示例数据库

1. 在启动页点击 **打开示例数据库**。应用会创建并连接本地 SQLite 示例库，同时打开一份查询。
2. 展开左侧连接及 `main`，可以看到 `customers`、`products`、`orders`、`order_items` 四张表。
3. 将光标放在示例 JOIN 内，点击执行或按 `⌘Return`。初始化数据返回 8 行，包含中文、NULL 和小数。
4. 双击单表查看记录，再练习筛选、排序、编辑和导出。
5. 修改查询并保存，从 SQL 库重新打开；在查询历史中找到已执行语句。

再次点击“打开示例数据库”会保留此前修改，不会重置数据。导入或修改过示例后，查询结果可能不再是最初的 8 行。示例文件见 [基础工作台示例](../examples/basic-workbench/README.md)。

## 创建自己的连接

1. 在数据库侧栏的新建连接入口选择数据库类型。
2. 为连接命名，按类型填写主机、端口、数据库、用户名和密码；SQLite 填写本地数据库文件路径。
3. 测试连接，核对目标，再保存和连接。
4. 展开连接中的数据库、schema 和表，查看列、索引等结构信息；具体层级随数据库类型变化。

SQLite 路径属于后端运行的机器。在本桌面包中，它就是当前 Mac 的文件路径。Web 远程部署时，该路径不属于浏览器所在电脑。

“导入连接配置”用于迁移连接信息；“导入表数据”用于把 CSV/Excel 写入表，两者是独立操作。连接能否成功取决于服务器可达性、凭据、数据库账号权限和当前包包含的驱动能力。

## 编写与执行 SQL

打开连接后新建查询，先核对页签下方独立上下文栏中的连接、数据库及 schema。其下的操作栏将执行/停止、SQL 编辑和事务操作分组显示。DataGrip macOS 预设的新建查询快捷键为 `⌘⇧L`。

- **执行**：点击执行或按 `⌘Return`。选中 SQL 时优先执行选中内容；无选中内容时按当前/全部执行设置运行。
- **停止**：查询运行中点击停止，或按 `⌘F2`。取消请求的响应时间取决于数据库和驱动。
- **格式化**：按 `⌘⌥L`。
- **查找/替换**：按 `⌘F` / `⌘R`。
- **查看执行计划**：使用编辑器工具栏的执行计划入口；是否可用取决于数据库类型和当前语句。DataGrip 预设没有为它设置默认键。

执行结果显示在下方的 **结果（Results）** 区，标题旁显示运行或完成状态，保留原有结果页签和表格操作。可切换结果页签、排序、筛选、复制或导出。使用结果栏右侧入口收起后，可点击工作区底部的结果恢复栏重新展开。编辑器的自动提交、事务及提交/回滚入口按当前连接能力显示，修改数据库前应确认目标与事务状态。

编辑器分栏较窄时，上下文选择器可以换行，执行文字仍保留；次要编辑操作收进该操作栏的“更多”，空间不足时可横向滚动操作栏。鼠标停留在图标上可查看提示。SQL 库和历史使用右侧工具条，隐藏后从全局 Tools 菜单打开。

## 编辑表数据

优先打开单表视图进行编辑。修改可编辑单元格后，检查待提交的变化及生成 SQL，再使用界面的保存/提交操作写入数据库。新增和删除记录同样应先确认目标行。

复杂 JOIN、聚合结果或缺少可识别行标识的结果可能是只读。SQL 编辑器中的 `⌘S` 用于保存 SQL；它不代表保存任意结果表中的待提交变化。数据是否已写入以表格状态和执行反馈为准。

## CSV 与 Excel 导入导出

**导入到表**：打开目标表的导入入口，选择 CSV 或 Excel 文件，确认分隔符/工作表、首行列名和字段映射，检查预览后执行。导入会写入目标数据库。

本仓库的 [`products.csv`](../examples/basic-workbench/products.csv) 可导入示例 `products` 表，按同名字段映射 5 列，首次导入新增 3 条记录。文件使用主键 101～103；重复导入可能发生唯一键冲突，应使用新的主键或新的练习表。

**导出结果**：在结果表中选择导出，指定 CSV 或 XLSX、所需数据范围和保存位置。原生包使用 macOS 文件选择与保存对话框。导出前确认界面选定的范围，不要仅凭当前页行数判断全部导出量。

此前构建已验证 SQLite 下 CSV/XLSX 往返，以及原生对话框中的 CSV 导入和 CSV/XLSX 导出；这些记录不等于新版主工作台已复验全部文件操作，也不代表所有数据库类型与导入选项均已验证。

## SQL 库与查询历史

普通查询页按 `⌘S`，或点击保存，可将 SQL 保存到 SQL 库，并关联连接及数据库。通过 SQL 库检索和重新打开常用查询。SQL 收藏存储在应用数据中，不等同于在文件系统中另存一个 `.sql` 文件；已有外部 SQL 文件的保存行为依该页签类型而定。

查询历史用于查找已执行的 SQL、执行状态和相关信息。DataGrip macOS 预设使用 `⌘⌥E` 打开或收起历史面板。保存 SQL 文本与执行 SQL 是两个动作：保存不会自动运行语句。

## 搜索操作

点击全局顶栏常驻的 **搜索操作** 入口，或在 DataGrip macOS 预设中按 `⌘⇧A`。输入中文名称或英文关键词，例如“格式化”、`format`、`query history`、`font`、`mcp`；搜索同时匹配操作名称、分组和内置关键词。

当前提供以下 **18 项常用操作**，范围以工作台已接入的动作清单为准，并非 DataGrip 或 DBX 的全部 IDE 操作。

| 分组 | 可搜索的操作 |
| --- | --- |
| 查询 | 新建查询、执行 SQL、停止查询、格式化 SQL、保存 SQL、刷新表数据、切换结果面板 |
| 导航 | 新建连接、快速打开对象、文件内容搜索、最近页签、数据库侧栏、查询历史、SQL 库 |
| 设置 | 打开设置、字体设置、快捷键设置、MCP 设置 |

结果显示当前实际配置的快捷键，包括自定义键位；未绑定的操作不显示快捷键。按 `↑` / `↓` 选择、Return 执行、Escape 关闭，也可点击操作。不可用的操作仍会显示，并说明原因，例如没有正在执行的查询或当前不是表数据页；它们无法执行。没有匹配项时显示空结果提示。

关闭弹窗会恢复先前焦点，再执行所选操作；执行前会重新检查该操作在当前页签是否可用。此前版本已验证搜索、禁用项和部分执行/焦点场景；新版已复验 `⌘⇧A` 搜索英文 `query history` 并打开历史，但不能视为全部操作已经通过。历史记录见 [DataGrip 快捷键说明](datagrip-keymap.md)。

## 从 SQL 跳转到表详情与定位表

在 SQL 编辑器中按住 **⌘（Windows/Linux 用 Ctrl）+ 鼠标左键点击表名**，打开该表的详情页，默认显示字段；可切换索引、外键、DDL 等页面，也可点击“查看数据”。重复点击同一张表会复用已打开的详情页。此操作不会执行表数据查询。设置 → 导航中的“表详情默认显示 DDL”可调整初始页面；旧的表数据跳转设置自动迁移为字段详情。

点击表详情页或表数据页右上角的 **定位图标**，会显示数据库侧栏、展开连接/数据库/Schema/表分组、选中并滚动到目标表。数据库侧栏标题栏也有定位图标，可定位当前表页签或 SQL 光标处的表。妨碍目标显示的搜索条件会清除；定位本身不会执行 SQL。对于多 Catalog 数据源，定位会严格匹配 Catalog；尚未加载且超出首批列表的表，需要先在对应 Catalog 下加载表列表。

## 使用 DataGrip macOS 快捷键

打开 **设置 → 快捷键 → 快捷键预设**，可选择 **DataGrip（macOS）** 或 **DBX 原有键位**，点击应用后生效。macOS 新配置默认使用 DataGrip 预设，其他平台继续使用 DBX 原有键位。

| 常用操作 | DataGrip macOS 预设 |
| --- | --- |
| 执行 / 停止查询 | `⌘Return` / `⌘F2` |
| 新建查询 | `⌘⇧L` |
| 最近页签 / 查询历史 | `⌘E` / `⌘⌥E` |
| 搜索操作 | `⌘⇧A` |
| 快速打开对象 | `⌘O` |
| 格式化 SQL | `⌘⌥L` |
| 查找 / 替换 | `⌘F` / `⌘R` |
| 行注释 / 块注释 | `⌘/` / `⌘⌥/` |
| 扩展 / 缩小选区 | `⌥↑` / `⌥↓` |
| 基础补全 | `⌃Space` |
| 数据库侧栏 | `⌘1` |
| 刷新数据 | `F5` |

符号：`⌘` Command、`⌥` Option、`⌃` Control、`⇧` Shift。

`⌘E` 打开当前仍打开的最近页签列表；松开 Command 后列表保持显示，方向键选择、Return 确认、Escape 取消。它的范围与 DataGrip 完整 Recent Files 不同。

`⌥↑` 按现有语义选择逻辑逐步扩展选区，`⌥↓` 逐步退回同一次扩展中的历史选区。手动移动光标、改变选区或编辑文本后，这段扩展历史会清空；没有历史时按 `⌥↓` 保持当前选区，不会误执行移动行。它不对任意手工选区推测缩小范围。此前构建的自动测试及原生检查覆盖了词、当前语句与光标之间的逐级扩展/恢复；其他选区组合仍需分别验收。

可以搜索操作名称并单独改键，单项“恢复默认”采用当前预设的默认值。手动切换预设会替换整个快捷键草稿，应用前可检查和修改。自动迁移旧 macOS 设置时，系统保留不同于旧默认值的自定义键和主动清空的绑定；如果新默认与自定义冲突，自定义优先。

当前预设迁移版本为 **2**：旧 DataGrip 版本升级后，搜索操作默认使用 `⌘⇧A`，缩小选区默认使用 `⌥↓`；“发送选中内容到 AI”默认不绑定快捷键，仍可从原入口使用或单独改键。DBX 原有预设中的 AI 快捷键保持原值。如果某个自定义操作占用新默认键，迁移会保留自定义并清空冲突的新绑定，可继续点击顶栏“搜索操作”打开。已完成当前版本迁移后，不会每次启动都重置配置。

DBX 保留 `F5` 全局刷新；`⌘R` 在编辑器中打开替换，在结果表格或等待重新加载的表数据页中刷新数据。整个工作台重新加载使用原生菜单或 `⌃⌘R`。`⌃Space` 可能被 macOS 输入法占用，可更改该操作绑定；功能键可能需要同时按 `Fn`。完整对照、迁移规则和功能差异见 [DataGrip 快捷键说明](datagrip-keymap.md)。

## 让外部 AI 客户端通过 MCP 访问

1. 启动 数据库工作台 桌面应用，创建并连接需要使用的数据库。
2. 在 **设置 → MCP** 中配置可见的连接、数据库范围和权限。初次使用可以只开放示例连接并选用“只读”，检查汇总后保存策略。工具策略与数据库账号权限共同限制访问能力。
3. 使用原生菜单 **工作台 → 显示 MCP 客户端配置**，定位自动生成的 `mcp-client.json`。
4. 按目标客户端的 MCP 配置方式使用该文件中的本机地址和认证信息。客户端需要支持 **Streamable HTTP**；此入口不是另起一个 stdio 服务。
5. 保持应用运行，让客户端先列出允许的连接和表，再执行查询。

默认端点是 `http://127.0.0.1:4227/mcp`。`mcp-client.json` 和 `mcp-token` 含凭据，不应加入版本控制或直接分享。本文不附真实 token；始终使用本机实际生成的配置，尤其在更改端口之后。

本桌面包的基础配置通常可列出 28 个静态工具，实际列表会受策略、插件和构建特性影响。除了连接、表结构与 SQL 操作，还提供：

| 工具 | 用途 |
| --- | --- |
| `dbx_list_saved_sql` | 检索 SQL 收藏摘要 |
| `dbx_get_saved_sql` | 读取指定收藏的 SQL 正文 |
| `dbx_save_sql` | 新建 SQL 收藏，不执行 SQL、不覆盖已有收藏 |
| `dbx_search_history` | 搜索查询历史，支持筛选与分页 |

这些工具与 GUI 使用同一存储。例如 MCP 新建的收藏可从 SQL 库打开。GUI 的所有功能并未全部提供 MCP 接口；CSV/Excel 文件导入导出、收藏更新/删除等不在当前新增工具范围内。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示 4227 端口已被占用 | 退出占用端口的实例，或为独立实例设置其他端口；应用不会自动接管未知服务。 |
| 提示同一数据目录已有实例运行 | 切换到已有窗口；独立实例应使用不同的数据目录和端口。 |
| 工作台加载异常 | 先用“工作台 → 重新加载工作台”；必要时用“重新启动后端”，并查看“显示后端日志”。 |
| MCP 认证失败 | 确认应用在运行、客户端使用当前端口及本机生成的 token；Web 登录密码和 MCP token 是不同凭据。 |
| MCP 看不到某个连接或工具 | 检查“设置 → MCP”的资源范围、工具策略、数据库权限和当前构建能力。 |
| 示例再次打开后数据没有恢复 | 示例设计为保留修改，不会自动重置。 |
| SQL 结果不能编辑 | 尝试单表视图，检查连接是否只读、是否有可靠行标识，以及结果是否来自 JOIN/聚合。 |
| 找不到 SQL 库或历史按钮 | 查看右侧工具条；若已关闭显示开关，可从 Tools 菜单打开，或使用操作搜索/查询历史快捷键。 |

高级启动可设置 `DBX_DESKTOP_PORT`（1024～65535）和 `DBX_DESKTOP_DATA_DIR`（绝对路径）。独立实例应同时设置不同端口与数据目录。开发版 `pnpm dev:basic` 使用前端 5173、API 4224 和 `.dbx-dev/basic`，与本桌面包的默认数据目录分开。
